# AI Document Q&A Bot 🤖📄

This is a simple AI application where you can upload a PDF document and ask questions based on its content. It uses **Retrieval-Augmented Generation (RAG)** concepts.

## 🛠️ Tech Stack
- **Python** (Programming Language)
- **Streamlit** (User Interface)
- **Groq API** (Llama 3 Model for super-fast answers)
- **PyPDF2** (To read PDF files)

## 🚀 How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Add your Groq API key in a `.env` file.
3. Run the app: `python -m streamlit run app.py`
